شرح طريقة مشاركة انترنت الكونفينق مع اجهزة اخرى بستعمال NetChecker

📱 الهاتف الأول:
  • فعل allow access from lan من داخل دارك تونل.
  • من داخل دارك تونل خلي HTTP Port 8080 بدل 8880.
  • حمل وثبت تطبيق NetChecker .
  • قم بمشاركة الاتصال (hotspot).
  • من داخل تطبيق NetChecker اضغط على تشغيل البروكسي.
  • سوف تظهر لك معلومات host ip و port.
📱 الجهاز الثاني:
  • تدخل إعدادات الوي فاي وتتصل بشبكة.
  • تقوم بإضافة بروكسي للشبكة وتحط host ip و port الي ظهرولك في تطبيق.

فيديو شرح الاستعمال
